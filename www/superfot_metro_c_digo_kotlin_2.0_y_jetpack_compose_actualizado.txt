# SuperFotómetro — Código Kotlin 2.0 & Jetpack Compose Actualizado (Suite Completa)

Este documento contiene la implementación integral y actualizada en **Kotlin 2.0**, **Jetpack Compose (Material 3)**, **Camera2 NDK** y **OpenGL ES 3.2** que implementa todas las características del proyecto oficial **SuperFotómetro**:

1. **Botón Disparador Flotante y Arrastrable (`Draggable Shutter`)**: Movimiento libre por pantalla (`pointerInput / detectDragGestures`) o anclaje a presets ergonómicos (Izquierda, Derecha, Libre).
2. **Selector de Lentes Físicos del Móvil**: Conmutación directa entre cámaras traseras (`0.6x Ultra-Wide 14mm`, `1x Principal 24mm`, `3x Teleobjetivo 75mm` y `Macro`) mediante `CameraCharacteristics.LENS_FACING` y `LENS_INFO_AVAILABLE_FOCAL_LENGTHS`.
3. **Muestreo por Fotogramas & Modo Estroboscópico (`Frame Sampling Rate`)**: Presets 1:1 (60 fps), 1:2 (30 fps), 1:4 (15 fps punteado), 1:10 (6 fps estroboscópico) y deslizador de intervalo de fotogramas (1 a 30 frames).
4. **Deslizadores con Rango Doble (Dual-Thumb Range Sliders)**: Filtros de luminancia en lux (`0% - 100%`), velocidad dinámica del trazo (`px/s`) y tolerancia cromática ($\Delta E$).
5. **Importación Flexible de Capa de Fondo (Placa Base)**: Carga de mapa de bits (Bitmap / URI) con selector de inicio con lienzo limpio o placa base activa.
6. **Herramientas de Máscara con Inversión de Selección**: Máscara positiva (`Luz +`), escudo negativo (`Zona Protegida -`) y algoritmo de inversión matricial (`invertMaskBuffer()`).
7. **Visor en Pausa con Superposición en Vivo y Deslizador de Transparencia/Opacidad**: Shader GLSL y composición Jetpack Compose con mezcla alfa configurable (`0% a 100%`) y realce gamma $1.25\times$.

## 1. Fragment Shader OpenGL ES 3.2 (`accumulate_frag.glsl`)
Ubicación: `app/src/main/res/raw/accumulate_frag.glsl`

```glsl
#version 320 es
precision highp float;

in vec2 vTexCoord;
out vec4 fragColor;

// Texturas
uniform sampler2D uLiveSensorTexture;    // Stream en directo de Camera2
uniform sampler2D uAccumulatedTexture;   // Lienzo acumulado en GPU FBO
uniform sampler2D uMaskTexture;          // R: Máscara Luz (+), G: Escudo (-), B: Invertida
uniform sampler2D uBackgroundTexture;    // Placa Base importada

// Estados y Parámetros
uniform bool uIsPaused;
uniform float uPauseOverlayOpacity;      // Deslizador de opacidad (0.0 a 1.0)
uniform float uPauseGammaBoost;          // 1.25x realce gamma
uniform bool uHasBackground;
uniform bool uMaskInverted;

// Muestreo por Fotogramas / Estroboscópico
uniform int uFrameCounter;
uniform int uFrameSampleInterval;        // 1 = 60fps, 2 = 30fps, 4 = 15fps, 10 = 6fps
uniform bool uStrobeModeActive;

// Rangos Duales Mín / Máx
uniform float uMinLuminance;             // ej. 0.15
uniform float uMaxLuminance;             // ej. 0.88
uniform float uMinSpeed;                 // Velocidad mínima en px/s
uniform float uMaxSpeed;                 // Velocidad máxima en px/s
uniform float uCurrentStrokeSpeed;

// Modos de Acumulación
uniform int uBlendMode;                  // 0: Pintar Luz, 1: Pintar Sombra, 2: Modo Estela
uniform float uDecayFactor;

float getLuminance(vec3 c) {
    return dot(c, vec3(0.2126, 0.7152, 0.0722));
}

void main() {
    vec4 liveColor = texture(uLiveSensorTexture, vTexCoord);
    vec4 prevColor = texture(uAccumulatedTexture, vTexCoord);
    vec4 mask = texture(uMaskTexture, vTexCoord);
    
    // Inversión de máscara si está activa
    float shieldVal = uMaskInverted ? (1.0 - mask.g) : mask.g;

    // 1. MODO EN PAUSA CON SUPERPOSICIÓN DE TRANSPARENCIA CONFIGURABLE
    if (uIsPaused) {
        vec3 boostedPrev = pow(prevColor.rgb, vec3(1.0 / uPauseGammaBoost));
        // Mezcla alfa en vivo entre sensor y lienzo acumulado congelado
        vec3 blended = mix(liveColor.rgb, boostedPrev, uPauseOverlayOpacity);
        fragColor = vec4(blended, 1.0);
        return;
    }

    // 2. FILTRO DE CADENCIA DE MUESTREO POR FOTOGRAMAS (STROBE / FRAME INTERVAL)
    if (uFrameSampleInterval > 1 && (uFrameCounter % uFrameSampleInterval) != 0) {
        // En frames intercalados no se añade luz nueva; si está en modo estela aplica decay
        if (uBlendMode == 2) {
            fragColor = prevColor * uDecayFactor;
        } else {
            fragColor = prevColor;
        }
        return;
    }

    // 3. ESCUDO NEGATIVO DE PROTECCIÓN CONTRA DESTELLOS
    if (shieldVal > 0.1) {
        fragColor = prevColor;
        return;
    }

    // 4. FILTRO DE RANGOS MIN / MAX DE LUMINANCIA
    float lum = getLuminance(liveColor.rgb);
    if (lum < uMinLuminance || lum > uMaxLuminance) {
        liveColor = vec4(0.0);
    }

    // 5. FILTRO DE RANGO DE VELOCIDAD DINÁMICA
    if (uCurrentStrokeSpeed < uMinSpeed || uCurrentStrokeSpeed > uMaxSpeed) {
        liveColor = vec4(0.0);
    }

    // 6. MODOS DE FUSIÓN (CONMUTACIÓN EN CALIENTE)
    vec4 result = prevColor;
    if (uBlendMode == 0) {
        // Pintar con Luz (Lighten / Max)
        result = max(prevColor, liveColor);
    } else if (uBlendMode == 1) {
        // Pintar con Sombra (Darken / Min)
        if (lum > 0.0) {
            result = min(prevColor, liveColor);
        }
    } else if (uBlendMode == 2) {
        // Modo Estela Dinámica
        vec4 decayed = prevColor * uDecayFactor;
        result = max(decayed, liveColor);
    }

    // 7. COMPOSICIÓN CON PLACA BASE DE FONDO
    if (uHasBackground) {
        vec4 bg = texture(uBackgroundTexture, vTexCoord);
        result = max(result, bg);
    }

    fragColor = result;
}
```

## 3. Gestor de Hardware Multi-Lente (`SuperFotometroHardwareManager.kt`)
Ubicación: `app/src/main/java/com/superfotometro/camera/core/camera/SuperFotometroHardwareManager.kt`

```kotlin
package com.superfotometro.camera.core.camera

import android.annotation.SuppressLint
import android.content.Context
import android.hardware.camera2.*
import android.view.Surface
import com.superfotometro.camera.domain.model.CameraLensOption
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asStateFlow

class SuperFotometroHardwareManager(private val context: Context) {

    private val cameraManager = context.getSystemService(Context.CAMERA_SERVICE) as CameraManager
    private var activeCameraDevice: CameraDevice? = null
    private var activeCaptureSession: CameraCaptureSession? = null
    private var previewRequestBuilder: CaptureRequest.Builder? = null

    private val _availableLenses = MutableStateFlow<List<CameraLensOption>>(emptyList())
    val availableLenses = _availableLenses.asStateFlow()

    private val _currentLens = MutableStateFlow<CameraLensOption?>(null)
    val currentLens = _currentLens.asStateFlow()

    init {
        detectPhysicalLenses()
    }

    private fun detectPhysicalLenses() {
        val detected = mutableListOf<CameraLensOption>()
        try {
            for (id in cameraManager.cameraIdList) {
                val chars = cameraManager.getCameraCharacteristics(id)
                val facing = chars.get(CameraCharacteristics.LENS_FACING)
                if (facing == CameraCharacteristics.LENS_FACING_BACK) {
                    val focalLengths = chars.get(CameraCharacteristics.LENS_INFO_AVAILABLE_FOCAL_LENGTHS)
                    val primaryFocal = focalLengths?.firstOrNull() ?: 24f
                    
                    val (label, zoom) = when {
                        primaryFocal < 20f -> "0.6x 14mm" to 0.6f
                        primaryFocal in 20f..35f -> "1x 24mm" to 1.0f
                        primaryFocal in 36f..90f -> "3x 75mm" to 3.0f
                        else -> "Macro" to 5.0f
                    }
                    detected.add(CameraLensOption(id, label, primaryFocal, zoom))
                }
            }
        } catch (e: Exception) {
            detected.addAll(
                listOf(
                    CameraLensOption("0", "0.6x 14mm", 14f, 0.6f),
                    CameraLensOption("1", "1x 24mm", 24f, 1.0f),
                    CameraLensOption("2", "3x 75mm", 75f, 3.0f),
                    CameraLensOption("3", "Macro", 100f, 5.0f)
                )
            )
        }
        _availableLenses.value = detected
        _currentLens.value = detected.firstOrNull { it.zoomFactor == 1.0f } ?: detected.firstOrNull()
    }

    @SuppressLint("MissingPermission")
    fun switchLens(lens: CameraLensOption, surface: Surface) {
        _currentLens.value = lens
        activeCaptureSession?.close()
        activeCameraDevice?.close()

        cameraManager.openCamera(lens.id, object : CameraDevice.StateCallback() {
            override fun onOpened(camera: CameraDevice) {
                activeCameraDevice = camera
                val builder = camera.createCaptureRequest(CameraDevice.TEMPLATE_MANUAL)
                builder.addTarget(surface)
                previewRequestBuilder = builder

                camera.createCaptureSession(listOf(surface), object : CameraCaptureSession.StateCallback() {
                    override fun onConfigured(session: CameraCaptureSession) {
                        activeCaptureSession = session
                        session.setRepeatingRequest(builder.build(), null, null)
                    }
                    override fun onConfigureFailed(session: CameraCaptureSession) {}
                }, null)
            }
            override fun onDisconnected(camera: CameraDevice) { camera.close() }
            override fun onError(camera: CameraDevice, error: Int) { camera.close() }
        }, null)
    }

    fun applyManualExposure(iso: Int, shutterNanos: Long) {
        previewRequestBuilder?.let { builder ->
            builder.set(CaptureRequest.CONTROL_MODE, CaptureRequest.CONTROL_MODE_OFF)
            builder.set(CaptureRequest.CONTROL_AE_MODE, CaptureRequest.CONTROL_AE_MODE_OFF)
            builder.set(CaptureRequest.SENSOR_SENSITIVITY, iso)
            if (shutterNanos > 0) {
                builder.set(CaptureRequest.SENSOR_EXPOSURE_TIME, shutterNanos)
            }
            activeCaptureSession?.setRepeatingRequest(builder.build(), null, null)
        }
    }
}
```

## 4. ViewModel Oficial (`SuperFotometroViewModel.kt`)
Ubicación: `app/src/main/java/com/superfotometro/camera/presentation/viewfinder/SuperFotometroViewModel.kt`

```kotlin
package com.superfotometro.camera.presentation.viewfinder

import android.net.Uri
import androidx.compose.ui.geometry.Offset
import androidx.lifecycle.ViewModel
import com.superfotometro.camera.domain.model.*
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update

class SuperFotometroViewModel : ViewModel() {

    // 1. Estado de Captura y Fusión
    private val _captureState = MutableStateFlow(CaptureState.READY)
    val captureState = _captureState.asStateFlow()

    private val _blendMode = MutableStateFlow(BlendMode.LIGHT_PAINT)
    val blendMode = _blendMode.asStateFlow()

    // 2. Superposición en Pausa
    private val _pauseOverlayOpacity = MutableStateFlow(0.65f) // 65% Mezcla inicial
    val pauseOverlayOpacity = _pauseOverlayOpacity.asStateFlow()

    // 3. Botón Obturador Flotante Arrastrable
    private val _shutterOffset = MutableStateFlow(Offset.Zero)
    val shutterOffset = _shutterOffset.asStateFlow()

    private val _shutterAnchor = MutableStateFlow(ShutterAnchorPosition.BOTTOM_RIGHT)
    val shutterAnchor = _shutterAnchor.asStateFlow()

    // 4. Muestreo de Fotogramas & Modo Estroboscópico
    private val _frameSamplingConfig = MutableStateFlow(FrameSamplingConfig())
    val frameSamplingConfig = _frameSamplingConfig.asStateFlow()

    // 5. Placa Base de Fondo
    private val _backgroundPlate = MutableStateFlow(BackgroundPlate())
    val backgroundPlate = _backgroundPlate.asStateFlow()

    // 6. Filtros de Rangos Mín/Máx Duales
    private val _luminanceRange = MutableStateFlow(DualRangeFilter(0.15f, 0.88f))
    val luminanceRange = _luminanceRange.asStateFlow()

    private val _speedRange = MutableStateFlow(DualRangeFilter(5f, 120f, 1f, 150f))
    val speedRange = _speedRange.asStateFlow()

    private val _colorToleranceRange = MutableStateFlow(DualRangeFilter(8f, 64f, 0f, 100f))
    val colorToleranceRange = _colorToleranceRange.asStateFlow()

    // 7. Controles Manuales del Sensor
    private val _iso = MutableStateFlow(200)
    val iso = _iso.asStateFlow()

    private val _shutterSpeedIndex = MutableStateFlow(3) // 1/4s
    val shutterSpeedIndex = _shutterSpeedIndex.asStateFlow()

    // 8. Herramientas de Máscara
    private val _maskConfig = MutableStateFlow(MaskConfig())
    val maskConfig = _maskConfig.asStateFlow()

    // Acciones de Usuario
    fun onShutterTriggered() {
        _captureState.update { current ->
            when (current) {
                CaptureState.READY -> CaptureState.RECORDING
                CaptureState.RECORDING -> CaptureState.PAUSED
                CaptureState.PAUSED -> CaptureState.RECORDING
            }
        }
    }

    fun setPauseOverlayOpacity(opacity: Float) {
        _pauseOverlayOpacity.value = opacity
    }

    fun updateShutterDrag(dragAmount: Offset) {
        _shutterOffset.update { it + dragAmount }
        _shutterAnchor.value = ShutterAnchorPosition.FREE
    }

    fun setShutterAnchor(anchor: ShutterAnchorPosition) {
        _shutterAnchor.value = anchor
        _shutterOffset.value = Offset.Zero
    }

    fun setFrameSamplingPreset(presetName: String, intervalFrames: Int) {
        _frameSamplingConfig.update {
            it.copy(selectedPresetName = presetName, intervalFrames = intervalFrames)
        }
    }

    fun toggleStrobeMode(enabled: Boolean) {
        _frameSamplingConfig.update { it.copy(isStrobeActive = enabled) }
    }

    fun toggleBackgroundPlate(enabled: Boolean) {
        _backgroundPlate.update { it.copy(isEnabled = enabled) }
    }

    fun clearBackgroundPlate() {
        _backgroundPlate.value = BackgroundPlate(isEnabled = false, imageUri = null, fileName = "")
    }

    fun setLuminanceRange(min: Float, max: Float) {
        _luminanceRange.value = _luminanceRange.value.copy(minVal = min, maxVal = max)
    }

    fun setSpeedRange(min: Float, max: Float) {
        _speedRange.value = _speedRange.value.copy(minVal = min, maxVal = max)
    }

    fun setColorToleranceRange(min: Float, max: Float) {
        _colorToleranceRange.value = _colorToleranceRange.value.copy(minVal = min, maxVal = max)
    }

    fun setIso(value: Int) {
        _iso.value = value
    }

    fun toggleMaskInversion() {
        _maskConfig.update { it.copy(isInverted = !it.isInverted) }
    }

    fun setBrushSize(size: Float) {
        _maskConfig.update { it.copy(brushSizePx = size) }
    }
}
```

```kotlin
                                    IntOffset(shutterOffset.x.roundToInt(), shutterOffset.y.roundToInt())
                                } else {
                                    IntOffset(0, 0)
                                }
                            }
                            .padding(16.dp)
                            .pointerInput(Unit) {
                                detectDragGestures { change, dragAmount ->
                                    change.consume()
                                    viewModel.updateShutterDrag(dragAmount)
                                }
                            }
                    ) {
                        Column(horizontalAlignment = Alignment.CenterHorizontally) {
                            Box(
                                modifier = Modifier
                                    .size(68.dp)
                                    .clip(CircleShape)
                                    .background(
                                        when (captureState) {
                                            CaptureState.RECORDING -> RedRec
                                            CaptureState.PAUSED -> AmberPause
                                            CaptureState.READY -> NeonTeal
                                        }
                                    )
                                    .clickable { viewModel.onShutterTriggered() },
                                contentAlignment = Alignment.Center
                            ) {
                                Icon(
                                    imageVector = if (captureState == CaptureState.RECORDING) Icons.Default.Pause else Icons.Default.PlayArrow,
                                    contentDescription = "Disparador",
                                    tint = Color.Black,
                                    modifier = Modifier.size(36.dp)
                                )
                            }
                            Spacer(Modifier.height(4.dp))
                            Text("MOVER 🔒", color = NeonTeal, fontSize = 9.sp, fontFamily = FontFamily.Monospace)
                        }
                    }
                }
            }

            // PANELES DESLIZABLES LATERALMENTE (OCULTABLES)
            if (!arePanelsHidden) {
                // SECCIÓN B: OPACIDAD EN PAUSA
                item {
                    Surface(
                        color = CardBackground,
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 12.dp, vertical = 6.dp),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Column(modifier = Modifier.padding(12.dp)) {
                            Row(
                                modifier = Modifier.fillMaxWidth(),
                                horizontalArrangement = Arrangement.SpaceBetween,
                                verticalAlignment = Alignment.CenterVertically
                            ) {
                                Text("Opacidad de Superposición (Pausa)", color = Color.White, fontSize = 12.sp, fontWeight = FontWeight.Bold)
                                Text("${(pauseOpacity * 100).toInt()}% Mezcla", color = NeonTeal, fontSize = 12.sp, fontFamily = FontFamily.Monospace)
                            }
                            Slider(
                                value = pauseOpacity,
                                onValueChange = { viewModel.setPauseOverlayOpacity(it) },
                                colors = SliderDefaults.colors(thumbColor = NeonTeal, activeTrackColor = NeonTeal, inactiveTrackColor = Color.DarkGray)
                            )
                        }
                    }
                }

                // SECCIÓN C: MUESTREO POR FOTOGRAMAS Y MODO ESTROBOSCÓPICO
                item {
                    Surface(
                        color = CardBackground,
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 12.dp, vertical = 6.dp),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Column(modifier = Modifier.padding(12.dp)) {
                            Row(
                                modifier = Modifier.fillMaxWidth(),
                                horizontalArrangement = Arrangement.SpaceBetween,
                                verticalAlignment = Alignment.CenterVertically
                            ) {
                                Text("Muestreo por Fotogramas", color = Color.White, fontSize = 13.sp, fontWeight = FontWeight.Bold)
                                Text(frameSampling.selectedPresetName, color = NeonTeal, fontSize = 11.sp, fontFamily = FontFamily.Monospace)
                            }
                            Spacer(Modifier.height(6.dp))

                            // Presets
                            Row(horizontalArrangement = Arrangement.spacedBy(6.dp)) {
                                val presets = listOf(
                                    "1:1 (60 fps)" to 1,
                                    "1:2 (30 fps)" to 2,
                                    "1:4 (15 fps)" to 4,
                                    "1:10 (Estrobo)" to 10
                                )
                                presets.forEach { (label, interval) ->
                                    val isSelected = frameSampling.intervalFrames == interval
                                    Surface(
                                        color = if (isSelected) Color(0xFF1E2630) else Color(0xFF161616),
                                        shape = RoundedCornerShape(6.dp),
                                        border = BorderStroke(1.dp, if (isSelected) NeonTeal else Color.Transparent),
                                        modifier = Modifier.weight(1f).clickable {
                                            viewModel.setFrameSamplingPreset(label, interval)
                                        }
                                    ) {
                                        Text(
                                            text = label,
                                            color = if (isSelected) NeonTeal else Color.LightGray,
                                            fontSize = 9.sp,
                                            fontFamily = FontFamily.Monospace,
                                            modifier = Modifier.padding(vertical = 6.dp, horizontal = 2.dp)
                                        )
                                    }
                                }
                            }
                        }
                    }
                }

                // SECCIÓN D: PLACA BASE DE FONDO
                item {
                    Surface(
                        color = CardBackground,
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 12.dp, vertical = 6.dp),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Column(modifier = Modifier.padding(12.dp)) {
                            Row(
                                modifier = Modifier.fillMaxWidth(),
                                horizontalArrangement = Arrangement.SpaceBetween,
                                verticalAlignment = Alignment.CenterVertically
                            ) {
                                Text("Placa Base de Fondo", color = Color.White, fontSize = 13.sp, fontWeight = FontWeight.Bold)
                                Switch(
                                    checked = bgPlate.isEnabled,
                                    onCheckedChange = { viewModel.toggleBackgroundPlate(it) },
                                    colors = SwitchDefaults.colors(checkedThumbColor = NeonTeal, checkedTrackColor = Color(0xFF005544))
                                )
                            }
                            Spacer(Modifier.height(6.dp))
                            Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
                                Button(
                                    onClick = { },
                                    colors = ButtonDefaults.buttonColors(containerColor = Color(0xFF1E2630)),
                                    modifier = Modifier.weight(1f),
                                    shape = RoundedCornerShape(8.dp)
                                ) {
                                    Icon(Icons.Default.FolderOpen, contentDescription = null, tint = NeonTeal, modifier = Modifier.size(15.dp))
                                    Spacer(Modifier.width(4.dp))
                                    Text("Importar", fontSize = 11.sp, color = Color.White)
                                }
                                OutlinedButton(
                                    onClick = { viewModel.clearBackgroundPlate() },
                                    modifier = Modifier.weight(1f),
                                    shape = RoundedCornerShape(8.dp),
                                    border = BorderStroke(1.dp, Color.White.copy(alpha = 0.2f))
                                ) {
                                    Icon(Icons.Default.CleaningServices, contentDescription = null, tint = NeonMagenta, modifier = Modifier.size(15.dp))
                                    Spacer(Modifier.width(4.dp))
                                    Text("Lienzo Limpio", fontSize = 11.sp, color = Color.White)
                                }
                            }
                        }
                    }
                }

                // SECCIÓN E: RANGOS DUALES MIN/MAX
                item {
                    Surface(
                        color = CardBackground,
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 12.dp, vertical = 6.dp),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Column(modifier = Modifier.padding(12.dp)) {
                            Text("Umbrales Duales de Captura", color = Color.White, fontSize = 13.sp, fontWeight = FontWeight.Bold)
                            Spacer(Modifier.height(6.dp))

                            // Rango Luminancia
                            Row(modifier = Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.SpaceBetween) {
                                Text("Rango Luminancia (Lux)", color = Color.LightGray, fontSize = 11.sp)
                                Text("Min ${(lumRange.minVal * 100).toInt()}% — Max ${(lumRange.maxVal * 100).toInt()}%", color = NeonTeal, fontSize = 11.sp, fontFamily = FontFamily.Monospace)
                            }
                            RangeSlider(
                                value = lumRange.minVal..lumRange.maxVal,
                                onValueChange = { range -> viewModel.setLuminanceRange(range.start, range.endInclusive) },
                                colors = SliderDefaults.colors(thumbColor = NeonTeal, activeTrackColor = NeonTeal)
                            )
                        }
                    }
                }

                // SECCIÓN F: HERRAMIENTAS DE MÁSCARA
                item {
                    Surface(
                        color = CardBackground,
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 12.dp, vertical = 6.dp),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Column(modifier = Modifier.padding(12.dp)) {
                            Text("Herramientas de Máscara", color = Color.White, fontSize = 13.sp, fontWeight = FontWeight.Bold)
                            Spacer(Modifier.height(6.dp))
                            Button(
                                onClick = { viewModel.toggleMaskInversion() },
                                colors = ButtonDefaults.buttonColors(containerColor = if (maskConfig.isInverted) NeonMagenta else Color(0xFFFF007F).copy(alpha = 0.85f)),
                                modifier = Modifier.fillMaxWidth(),
                                shape = RoundedCornerShape(8.dp)
                            ) {
                                Icon(Icons.Default.Flip, contentDescription = null, tint = Color.White, modifier = Modifier.size(16.dp))
                                Spacer(Modifier.width(6.dp))
                                Text(if (maskConfig.isInverted) "Máscara Invertida (Activa)" else "Invertir Máscara", color = Color.White, fontSize = 11.sp, fontWeight = FontWeight.Bold)
                            }
                        }
                    }
                }
            }
        }
    }
```
