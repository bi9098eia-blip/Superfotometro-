# LuminaCam Pro — Código Kotlin 2.0 & Jetpack Compose Actualizado (Nueva Suite Completa)

Este documento contiene la implementación integral y actualizada en **Kotlin 2.0**, **Jetpack Compose (Material 3)**, **Camera2 NDK** y **OpenGL ES 3.2** que implementa todas las nuevas características incorporadas en la última versión de **LuminaCam Pro**:

1. **Botón Disparador Flotante y Arrastrable (`Draggable Shutter`)**: Puede moverse libremente por la pantalla mediante gestos táctiles (`pointerInput / detectDragGestures`) o anclarse rápidamente a presets ergonómicos (Izquierda, Derecha, Libre).
2. **Selector de Lentes Físicos del Móvil**: Conmutación directa entre cámaras traseras del hardware (`0.6x Ultra-Wide 14mm`, `1x Principal 24mm`, `3x Teleobjetivo 75mm` y `Macro`) mediante `CameraCharacteristics.LENS_FACING` y `LENS_INFO_AVAILABLE_FOCAL_LENGTHS`.
3. **Deslizadores con Rango Doble (Mínimo y Máximo / Dual-Thumb Range Sliders)**: Implementados con `RangeSlider` de Jetpack Compose para filtrar luminancia en lux (`0% - 100%`), velocidad dinámica del trazo (`px/s`) y tolerancia cromática ($\Delta E$).
4. **Importación Flexible de Capa de Fondo (Placa Base)**: Carga de mapa de bits (Bitmap / URI) para previsualizar una fotografía guía previa, con conmutador para iniciar la sesión con lienzo limpio o con placa base activa.
5. **Herramientas de Máscara con Inversión de Selección**: Máscara positiva (`Luz +`), escudo negativo (`Zona Protegida -`) y algoritmo de inversión matricial de máscara (`invertMaskBuffer()`).
6. **Visor en Pausa con Superposición en Vivo y Deslizador de Transparencia/Opacidad**: Shader GLSL y composición Jetpack Compose con mezcla alfa configurable (`0% a 100%`) para calibrar la opacidad del lienzo acumulado sobre el sensor en tiempo real.

## 1. Fragment Shader OpenGL ES 3.2 Actualizado (`accumulate_frag.glsl`)
Ubicación: `app/src/main/res/raw/accumulate_frag.glsl`

```glsl
#version 320 es
precision highp float;

in vec2 vTexCoord;
out vec4 fragColor;

// Texturas
uniform sampler2D uLiveSensorTexture;    // Stream en directo de Camera2
uniform sampler2D uAccumulatedTexture;   // Lienzo acumulado en GPU FBO
uniform sampler2D uMaskTexture;          // R: Máscara Luz (+), G: Escudo (-), B: Invertida
uniform sampler2D uBackgroundTexture;    // Placa Base importada

// Estados y Parámetros
uniform bool uIsPaused;
uniform float uPauseOverlayOpacity;      // Deslizador de opacidad (0.0 a 1.0)
uniform float uPauseGammaBoost;          // 1.25x realce
uniform bool uHasBackground;
uniform bool uMaskInverted;

// Rangos Duales Mín / Máx
uniform float uMinLuminance;             // ej. 0.15
uniform float uMaxLuminance;             // ej. 0.88
uniform float uMinSpeed;                 // Velocidad mínima en px/s
uniform float uMaxSpeed;                 // Velocidad máxima en px/s
uniform float uCurrentStrokeSpeed;

// Modos de Acumulación
uniform int uBlendMode;                  // 0: Pintar Luz, 1: Pintar Sombra, 2: Modo Estela
uniform float uDecayFactor;

float getLuminance(vec3 c) {
    return dot(c, vec3(0.2126, 0.7152, 0.0722));
}

void main() {
    vec4 liveColor = texture(uLiveSensorTexture, vTexCoord);
    vec4 prevColor = texture(uAccumulatedTexture, vTexCoord);
    vec4 mask = texture(uMaskTexture, vTexCoord);
    
    // Si la máscara está invertida, alternamos la lógica de los canales
    float shieldVal = uMaskInverted ? (1.0 - mask.g) : mask.g;

    // 1. MODO EN PAUSA CON SUPERPOSICIÓN DE TRANSPARENCIA CONFIGURABLE
    if (uIsPaused) {
        vec3 boostedPrev = pow(prevColor.rgb, vec3(1.0 / uPauseGammaBoost));
        // Mezcla alfa entre el sensor en vivo y el lienzo acumulado congelado
        vec3 blended = mix(liveColor.rgb, boostedPrev, uPauseOverlayOpacity);
        fragColor = vec4(blended, 1.0);
        return;
    }

    // 2. ESCUDO NEGATIVO DE PROTECCIÓN CONTRA DESTELLOS
    if (shieldVal > 0.1) {
        fragColor = prevColor;
        return;
    }

    // 3. FILTRO DE RANGOS MIN / MAX DE LUMINANCIA
    float lum = getLuminance(liveColor.rgb);
    if (lum < uMinLuminance || lum > uMaxLuminance) {
        liveColor = vec4(0.0);
    }

    // 4. FILTRO DE RANGO DE VELOCIDAD DINÁMICA
    if (uCurrentStrokeSpeed < uMinSpeed || uCurrentStrokeSpeed > uMaxSpeed) {
        liveColor = vec4(0.0);
    }

    // 5. MODOS DE FUSIÓN (CONMUTACIÓN EN CALIENTE)
    vec4 result = prevColor;
    if (uBlendMode == 0) {
        // Pintar con Luz (Lighten / Max)
        result = max(prevColor, liveColor);
    } else if (uBlendMode == 1) {
        // Pintar con Sombra (Darken / Min)
        if (lum > 0.0) {
            result = min(prevColor, liveColor);
        }
    } else if (uBlendMode == 2) {
        // Modo Estela Dinámica
        vec4 decayed = prevColor * uDecayFactor;
        result = max(decayed, liveColor);
    }

    // 6. COMPOSICIÓN CON PLACA BASE DE FONDO
    if (uHasBackground) {
        vec4 bg = texture(uBackgroundTexture, vTexCoord);
        result = max(result, bg);
    }

    fragColor = result;
}
```

## 3. Gestor de Hardware Multi-Lente y Exposición (`CameraHardwareManager.kt`)
Ubicación: `app/src/main/java/com/lightpainting/camera/core/camera/CameraHardwareManager.kt`

```kotlin
package com.lightpainting.camera.core.camera

import android.annotation.SuppressLint
import android.content.Context
import android.hardware.camera2.*
import android.view.Surface
import com.lightpainting.camera.domain.model.CameraLensOption
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asStateFlow

class CameraHardwareManager(private val context: Context) {

    private val cameraManager = context.getSystemService(Context.CAMERA_SERVICE) as CameraManager
    private var activeCameraDevice: CameraDevice? = null
    private var activeCaptureSession: CameraCaptureSession? = null
    private var previewRequestBuilder: CaptureRequest.Builder? = null

    private val _availableLenses = MutableStateFlow<List<CameraLensOption>>(emptyList())
    val availableLenses = _availableLenses.asStateFlow()

    private val _currentLens = MutableStateFlow<CameraLensOption?>(null)
    val currentLens = _currentLens.asStateFlow()

    init {
        detectPhysicalLenses()
    }

    private fun detectPhysicalLenses() {
        val detected = mutableListOf<CameraLensOption>()
        try {
            for (id in cameraManager.cameraIdList) {
                val chars = cameraManager.getCameraCharacteristics(id)
                val facing = chars.get(CameraCharacteristics.LENS_FACING)
                if (facing == CameraCharacteristics.LENS_FACING_BACK) {
                    val focalLengths = chars.get(CameraCharacteristics.LENS_INFO_AVAILABLE_FOCAL_LENGTHS)
                    val primaryFocal = focalLengths?.firstOrNull() ?: 24f
                    
                    val (label, zoom) = when {
                        primaryFocal < 20f -> "0.6x 14mm" to 0.6f
                        primaryFocal in 20f..35f -> "1x 24mm" to 1.0f
                        primaryFocal in 36f..90f -> "3x 75mm" to 3.0f
                        else -> "Macro" to 5.0f
                    }
                    detected.add(CameraLensOption(id, label, primaryFocal, zoom))
                }
            }
        } catch (e: Exception) {
            // Lentes virtuales de respaldo para testing o emulador
            detected.addAll(
                listOf(
                    CameraLensOption("0", "0.6x 14mm", 14f, 0.6f),
                    CameraLensOption("1", "1x 24mm", 24f, 1.0f),
                    CameraLensOption("2", "3x 75mm", 75f, 3.0f),
                    CameraLensOption("3", "Macro", 100f, 5.0f)
                )
            )
        }
        _availableLenses.value = detected
        _currentLens.value = detected.firstOrNull { it.zoomFactor == 1.0f } ?: detected.firstOrNull()
    }

    @SuppressLint("MissingPermission")
    fun switchLens(lens: CameraLensOption, surface: Surface) {
        _currentLens.value = lens
        activeCaptureSession?.close()
        activeCameraDevice?.close()

        cameraManager.openCamera(lens.id, object : CameraDevice.StateCallback() {
            override fun onOpened(camera: CameraDevice) {
                activeCameraDevice = camera
                val builder = camera.createCaptureRequest(CameraDevice.TEMPLATE_MANUAL)
                builder.addTarget(surface)
                previewRequestBuilder = builder

                camera.createCaptureSession(listOf(surface), object : CameraCaptureSession.StateCallback() {
                    override fun onConfigured(session: CameraCaptureSession) {
                        activeCaptureSession = session
                        session.setRepeatingRequest(builder.build(), null, null)
                    }
                    override fun onConfigureFailed(session: CameraCaptureSession) {}
                }, null)
            }
            override fun onDisconnected(camera: CameraDevice) { camera.close() }
            override fun onError(camera: CameraDevice, error: Int) { camera.close() }
        }, null)
    }

    fun applyManualExposure(iso: Int, shutterNanos: Long) {
        previewRequestBuilder?.let { builder ->
            builder.set(CaptureRequest.CONTROL_MODE, CaptureRequest.CONTROL_MODE_OFF)
            builder.set(CaptureRequest.CONTROL_AE_MODE, CaptureRequest.CONTROL_AE_MODE_OFF)
            builder.set(CaptureRequest.SENSOR_SENSITIVITY, iso)
            if (shutterNanos > 0) {
                builder.set(CaptureRequest.SENSOR_EXPOSURE_TIME, shutterNanos)
            }
            activeCaptureSession?.setRepeatingRequest(builder.build(), null, null)
        }
    }
}
```

## 4. ViewModel Completo con Lógica de Estados (`LuminaCamViewModel.kt`)
Ubicación: `app/src/main/java/com/lightpainting/camera/presentation/viewfinder/LuminaCamViewModel.kt`

```kotlin
package com.lightpainting.camera.presentation.viewfinder

import android.net.Uri
import androidx.compose.ui.geometry.Offset
import androidx.lifecycle.ViewModel
import com.lightpainting.camera.domain.model.*
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update

class LuminaCamViewModel : ViewModel() {

    // 1. Estado de Captura y Renderizado
    private val _captureState = MutableStateFlow(CaptureState.READY)
    val captureState = _captureState.asStateFlow()

    private val _blendMode = MutableStateFlow(BlendMode.LIGHT_PAINT)
    val blendMode = _blendMode.asStateFlow()

    // 2. Superposición en Pausa
    private val _pauseOverlayOpacity = MutableStateFlow(0.65f) // 65% Mezcla por defecto
    val pauseOverlayOpacity = _pauseOverlayOpacity.asStateFlow()

    // 3. Botón Obturador Flotante Arrastrable
    private val _shutterOffset = MutableStateFlow(Offset.Zero)
    val shutterOffset = _shutterOffset.asStateFlow()

    private val _shutterAnchor = MutableStateFlow(ShutterAnchorPosition.BOTTOM_RIGHT)
    val shutterAnchor = _shutterAnchor.asStateFlow()

    // 4. Placa Base de Fondo
    private val _backgroundPlate = MutableStateFlow(BackgroundPlate())
    val backgroundPlate = _backgroundPlate.asStateFlow()

    // 5. Filtros de Rangos Mín/Máx Duales
    private val _luminanceRange = MutableStateFlow(DualRangeFilter(0.15f, 0.88f))
    val luminanceRange = _luminanceRange.asStateFlow()

    private val _speedRange = MutableStateFlow(DualRangeFilter(5f, 120f, 1f, 150f))
    val speedRange = _speedRange.asStateFlow()

    private val _colorToleranceRange = MutableStateFlow(DualRangeFilter(8f, 64f, 0f, 100f))
    val colorToleranceRange = _colorToleranceRange.asStateFlow()

    // 6. Controles Manuales del Sensor
    private val _iso = MutableStateFlow(200)
    val iso = _iso.asStateFlow()

    private val _shutterSpeedIndex = MutableStateFlow(3) // 1/4s
    val shutterSpeedIndex = _shutterSpeedIndex.asStateFlow()

    // 7. Herramientas de Máscara
    private val _maskConfig = MutableStateFlow(MaskConfig())
    val maskConfig = _maskConfig.asStateFlow()

    // Acciones de Usuario
    fun onShutterTriggered() {
        _captureState.update { current ->
            when (current) {
                CaptureState.READY -> CaptureState.RECORDING
                CaptureState.RECORDING -> CaptureState.PAUSED
                CaptureState.PAUSED -> CaptureState.RECORDING
            }
        }
    }

    fun setPauseOverlayOpacity(opacity: Float) {
        _pauseOverlayOpacity.value = opacity
    }

    fun updateShutterDrag(dragAmount: Offset) {
        _shutterOffset.update { it + dragAmount }
        _shutterAnchor.value = ShutterAnchorPosition.FREE
    }

    fun setShutterAnchor(anchor: ShutterAnchorPosition) {
        _shutterAnchor.value = anchor
        _shutterOffset.value = Offset.Zero
    }

    fun toggleBackgroundPlate(enabled: Boolean) {
        _backgroundPlate.update { it.copy(isEnabled = enabled) }
    }

    fun importBackgroundUri(uri: Uri, fileName: String) {
        _backgroundPlate.value = BackgroundPlate(isEnabled = true, imageUri = uri, fileName = fileName)
    }

    fun clearBackgroundPlate() {
        _backgroundPlate.value = BackgroundPlate(isEnabled = false, imageUri = null, fileName = "")
    }

    fun setLuminanceRange(min: Float, max: Float) {
        _luminanceRange.value = _luminanceRange.value.copy(minVal = min, maxVal = max)
    }

    fun setSpeedRange(min: Float, max: Float) {
        _speedRange.value = _speedRange.value.copy(minVal = min, maxVal = max)
    }

    fun setColorToleranceRange(min: Float, max: Float) {
        _colorToleranceRange.value = _colorToleranceRange.value.copy(minVal = min, maxVal = max)
    }

    fun setIso(value: Int) {
        _iso.value = value
    }

    fun setShutterSpeedIndex(index: Int) {
        _shutterSpeedIndex.value = index
    }

    fun toggleMaskInversion() {
        _maskConfig.update { it.copy(isInverted = !it.isInverted) }
    }

    fun setBrushSize(size: Float) {
        _maskConfig.update { it.copy(brushSizePx = size) }
    }

    fun setBrushHardness(hardness: Float) {
        _maskConfig.update { it.copy(brushHardness = hardness) }
    }
}
```

## 6. Instrucciones de Compilación y Verificación

1. **Gradle Sync**: Abre Android Studio Iguana / Jellyfish o Cloud Workstations y pulsa en **Sync Project with Gradle Files**.
2. **Ubicación del Shader**: Verifica que `accumulate_frag.glsl` esté ubicado en `app/src/main/res/raw/accumulate_frag.glsl`.
3. **Ejecución**:
   - Conecta tu terminal Android con depuración USB o lanza el emulador cloud y ejecuta `./gradlew assembleDebug`.
   - Podrás interactuar arrastrando el botón de obturador, alternando lentes físicas y manipulando los deslizadores de doble rango tanto en pausa como en grabación activa.
